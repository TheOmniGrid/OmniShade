# Contributing

This is a documentation and support repository. It does not accept or publish OmniShade application source code, runtime binaries, installers, shaders, presets, private test material, or delivery links.

## Good contributions

- reproducible game compatibility reports;
- corrections to public documentation;
- accessibility and translation corrections;
- clear feature requests grounded in a player workflow; and
- sanitized screenshots that demonstrate a public documentation problem.

Use [GitHub Issues](https://github.com/TheOmniGrid/OmniShade/issues) for ordinary reports. Small documentation pull requests are welcome if they preserve the public/private boundary and do not add binary or runnable content.

## Please do not submit

- application source or reverse-engineered code;
- installer, DLL, shader, preset, or archive files;
- private download or supporter attachment URLs;
- copyrighted game assets;
- account identifiers, personal paths, tokens, or unsanitized logs; or
- claims of universal compatibility or performance without reproducible evidence.

Security-sensitive reports must follow [SECURITY.md](SECURITY.md) instead of using a public issue or pull request.
