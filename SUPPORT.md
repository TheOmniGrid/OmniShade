# Support

## Before reporting a problem

1. Confirm that the game starts without OmniShade.
2. Confirm that you selected the actual game executable rather than a launcher or updater.
3. Note the graphics API, executable architecture, Windows version, GPU, and driver version.
4. Re-run Setup and use **Verify and repair OmniShade** before manually deleting files.
5. Reproduce once with all effects disabled to separate host problems from effect problems.
6. Review the game's anti-cheat and modification policy.

## A useful bug report includes

- OmniShade version.
- Game name and exact executable filename.
- Graphics API and 32/64-bit architecture.
- Whether the game reaches its menu before the problem appears.
- Minimal reproduction steps.
- Whether the issue persists with all effects disabled.
- The last 100–200 relevant log lines.
- A screenshot when the problem is visual or UI-related.

Remove usernames, full local paths, account identifiers, access tokens, and other personal information before posting logs or screenshots publicly. Never upload the installer, runtime DLL, private download link, or supporter attachment to an issue.
