# OmniShade 1.0.0 highlights

- Stable consumer branding and 1.0.0 installer channel.
- Native x86/x64 executable detection.
- Direct3D, DirectDraw, OpenGL, Vulkan, DXVK, RTX Remix and optional OpenXR routing.
- Game discovery, search and renderer summary.
- Transactional install, update, repair and uninstall flows.
- Integrated OmniToggler support.
- Balanced and Performance profiles.
- Ten-language Setup: English, German, Spanish, French, Romanian, Russian,
  Simplified Chinese, Japanese, Korean, and Turkish, with live switching,
  local persistence, first-run Windows detection, and safe English fallback.
- Compact OmniVex RC interface with keyboard focus, contextual help and reduced-motion support.
- Movable and resizable Omni Night player overlay with bounded saved placement.
- Player-facing far-plane, upside-down, reversed and logarithmic depth controls.
- Full Escape/Home close-key consumption so DirectInput games do not receive an unmatched release event when the overlay closes.
- No inherited ReShade update banner or consumer-startup product-feed query.
- Local Omni Health Check for runtime/shader readiness, active stack,
  depth/motion availability, HDR state, reload recovery, and actionable warnings.
- Transactional reload, cache validation, Depth Buffer 2.0, motion/semantic
  services, HDR/display metadata coordination, and OpenXR-aware compatibility.
- Consumer builds keep render-graph capture, provider labs, calibration,
  authoring, and telemetry surfaces outside the normal player interface.
