# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability, unsafe installer behavior, path-traversal problem, signature/trust failure, or other security-sensitive report.

Email **[omnivex@theomnigrid.biz](mailto:omnivex@theomnigrid.biz)** with:

- the affected OmniShade version;
- the game executable architecture and graphics API, when relevant;
- concise reproduction steps;
- the security impact you observed;
- sanitized logs or screenshots; and
- whether the details may be acknowledged publicly after a fix.

Do not send passwords, access tokens, private download URLs, unrelated personal data, or copyrighted game files. If an attachment is necessary, ask first.

## Scope

Security reports may cover the official OmniShade installer, runtime, configuration handling, update/repair/uninstall behavior, and this documentation repository. Ordinary compatibility problems and feature requests belong in [GitHub Issues](https://github.com/TheOmniGrid/OmniShade/issues).

Support is best-effort. Receipt will be acknowledged when possible, and publication should wait until the issue has been understood and users have a reasonable opportunity to update.
